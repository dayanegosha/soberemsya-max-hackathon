# Данные и источники

В рабочем сценарии Nominatim определяет город России, а Overpass API загружает именованные места OpenStreetMap рядом с точкой встречи. Для Москвы, Санкт-Петербурга и Казани в интерфейсе есть расширенные списки ориентиров. Режим работы, цена и наличие мест требуют проверки перед выходом.

`data/activities.json` используется как воспроизводимый тестовый набор. Каждая запись помечена `is_demo_data=true`, содержит происхождение и дату подготовки. Эти записи не выдаются за актуальную афишу.

| Источник | Назначение и потенциальные данные | Статус |
|---|---|---|
| [Культура.РФ](https://www.culture.ru/) | События, учреждения, даты, цена, условия посещения | Исследование и масштабирование |
| [PRO.Культура.РФ](https://pro.culture.ru/) | Публикация культурных событий и данные организаторов | Будущая интеграция после проверки условий доступа |
| [АИС «Статистика» Минкультуры](https://stat.mkrf.ru/) | Отраслевая статистика, учреждения, сравнение территорий | Контекст исследования, не каталог живых событий |
| [Минспорт России](https://minsport.gov.ru/) — Единый календарный план | Спортивные мероприятия и расписание | Будущие данные, применимость к вечернему досугу требует проверки |
| [Минспорт России](https://minsport.gov.ru/) — Всероссийский реестр объектов спорта | Объекты спорта и территориальная привязка | Масштабирование; реестр не гарантирует доступность посещения |
| [Путешествуем.рф](https://путешествуем.рф/) | Достопримечательности и туристические маршруты | Масштабирование |
| [Добро.рф](https://dobro.ru/) | Волонтёрские события, условия участия | Масштабирование после проверки регистрационных ограничений |
| [Пушкинская карта](https://www.culture.ru/pushkinskaya-karta) | Программа и культурные мероприятия | Не используется; не обещаем оплату картой |
| [ФИАС](https://fias.nalog.ru/) | Нормализация адресов и территории | Будущая нормализация |

Не заявляем наличие открытого API или разрешение на массовую выгрузку для какого-либо источника. Перед подключением проверить лицензию, технический доступ, право распространения и частоту обновления. `source_updated_at` в demo означает дату подготовки, а не онлайн-проверки.

Архитектура импорта: источник → проверка лицензии и актуальности → нормализованный Activity → валидация города, координат, часов и цен → версия каталога → ранжирование. Общая логика выбора одинакова для всех городов.
