# VK Sans Display

Шрифт добавлен по запросу владельца проекта из установленного на его Mac набора `/Library/Fonts/Managed`. Начертания Light, Regular, Medium, DemiBold и Bold. Оригинальные OTF сохранены без изменения.

Файлы отдаются самим приложением; сторонних font-CDN и зависимости от установленных шрифтов посетителя нет. Эти файлы не являются разработкой команды; права на шрифт принадлежат его правообладателю.
