# VK Sans Display

шрифт взят из локального набора `/Library/Fonts/Managed` на Mac владельца проекта. используются начертания light, regular, medium, DemiBold и bold. оригинальные OTF сохранены без изменений.

приложение раздаёт файлы шрифта самостоятельно, без сторонних CDN. права на шрифт принадлежат его правообладателю.
